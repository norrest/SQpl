Services

Enable or disable selected functions.


AirPlay lets you stream audio to the player from Apple devices.

$_system_select[shairport1] $_system_select[shairport0]
Enables shairport-sync. Turn OFF if you never use AirPlay.

Allows remote control of the player using UPnP controller apps (Play To).

$_system_select[upnpmpdcli1] $_system_select[upnpmpdcli0]
Enables upmpdcli (MPD UPnP renderer/control). Turn OFF if you don’t use UPnP apps.

Shows other UPnP/DLNA servers in the network and can mount them into the player as a folder (usually under /mnt/UPNP). This may create extra background traffic on SSDP (UDP 1900) and can be heavy on low-power devices.

$_system_select[djmount1] $_system_select[djmount0]
Enables djmount. If you don’t use UPnP libraries, keep this OFF.

Shares your local music folder to the network as a DLNA server. Other devices (TV, phone apps, streamers) will see the player as a media library. Can increase disk activity and CPU usage during scanning.

$_system_select[minidlna1] $_system_select[minidlna0]
Enables minidlna.

Compatibility

Fixes for specific USB receivers and DACs.

$_system_select[cmediafix1] $_system_select[cmediafix0]
Default: OFF. If you hear clicks or pops between tracks or when sample rate changes, this can help. Internally it sends a quick pause → pause to re-sync playback. May slightly affect gapless playback.

Generic implicit feedback mode for some async USB DACs. Enable only if you have clicks or sync drift.

$_system_select[usbi_fb1] $_system_select[usbi_fb0]
Compatibility option for some asynchronous USB DACs that click, pop, or glitch on track changes, seeks, or sample-rate switches. It changes how the USB audio driver keeps the stream in sync, which can improve stability on certain DACs or USB controllers. Keep it OFF if everything is already stable. Default: OFF. Reboot required.

Auto clock selection for UAC2 devices. Usually keep ON.

$_system_select[usb_clk1] $_system_select[usb_clk0]
Lets the USB audio driver automatically pick the best clock/sync mode for UAC2 devices. Usually this improves compatibility and reduces issues when switching sample rates, so it should normally stay ON. Turn it OFF only if a specific DAC works worse with it enabled. Default: ON. Reboot required.
